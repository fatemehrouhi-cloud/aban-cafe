# ABAN Cafe
## About the Project

ABAN Cafe is a responsive cafe website built using **HTML, CSS, and JavaScript**.

The website features a warm and relaxing cafe-inspired design, with a combination of **cream, brown, and pastel green** colors. It also includes animations to create a more engaging user experience.

### Features

* Responsive design
* Cafe-themed user interface
* Cream, brown, and pastel green color palette
* CSS animations
* Built with HTML, CSS, and JavaScript
## Technologies Used

- **HTML5** — Structure and content
- **CSS3** — Styling, layout, responsiveness, and animations
- **JavaScript** — Interactivity and dynamic behavior
